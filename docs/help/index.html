Welcome to ShuttleSCP

ShuttleSCP copies files between your computer and other computers, called servers: a web host, a home server, a computer at work, a cloud machine. It can also copy files directly from one server to another.

You do not need to know the command line. If words like SSH, SFTP or host key are new to you, start with SSH, SFTP, SCP and FTP: it explains them in plain words.

The window at a glance

PartWhat it is
Left paneThe files on this computer (or, in a site-to-site session, on the first server).
Right paneThe files on the server you are connected to.
Tabs above the panesEach tab is a session: one connection, with its own panes and transfers. New Connection opens another.
Transfers, at the bottomWhat is being copied (Queue), and what has finished (Completed) or failed (Failed).
Status barWhere you are connected, and how many files are copied at once (click it to set a limit).

The quick start

  1. Open File › Login… (Ctrl+L).
  2. Click New Site, fill in the server's host name, your user name and password, and click Save.
  3. Click Login. The first time, ShuttleSCP asks whether you trust the server: see Host keys.
  4. Drag files from one pane to the other. That's it: the copy appears under Transfers.

This guide is the one for the version you have installed, and works without an internet connection. Open it at any time with Help › User Guide or F1.
