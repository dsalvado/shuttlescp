ShuttleSCP

Install

Linux

  1. Download the AppImage above. It is one file holding ShuttleSCP and everything it needs.
  2. Make it runnable, from your file manager (Properties › Permissions › "Allow executing file as program") or a terminal: 
    chmod +x ShuttleSCP-*-x86_64.AppImage
  3. Run it. ShuttleSCP adds itself to your desktop's app launcher the first time, and from then on checks for new versions and can update itself (Help › Check for Updates).

It runs on 64-bit Linux from 2020 on: it is tested on Ubuntu 20.04, 22.04 and 24.04 and on Debian 12 and 13, and Fedora, Linux Mint and the like work the same way.

macOS

  1. Download the disk image (.dmg) above, open it and drag ShuttleSCP onto Applications.
  2. The first time, right-click (or Control-click) ShuttleSCP in Applications and choose Open, then Open again. ShuttleSCP is free and is not signed with a paid Apple Developer ID, so macOS asks this once. If it only offers "Move to Trash", open System Settings › Privacy & Security and click "Open Anyway".
  3. ShuttleSCP checks for new versions and offers to download them (ShuttleSCP › Check for Updates in the Help menu).

It needs a Mac with Apple silicon (M1 or later) and macOS 14 (Sonoma) or newer.

Windows

  1. Download the installer above and run it. It installs ShuttleSCP for your user only, with no administrator rights needed, and adds it to the Start menu.
  2. The first time, Windows SmartScreen may say "Windows protected your PC": click "More info", then "Run anyway". ShuttleSCP is free and its installer is not signed with a paid code-signing certificate, so Windows asks this once.
  3. ShuttleSCP checks for new versions and can update itself (Help › Check for Updates). To remove it, use Settings › Apps.

It needs 64-bit Windows 10 or 11.

To check a download by hand, compare it with the release's checksums: sha256sum --check SHA256SUMS (on a Mac: shasum -a 256 --check SHA256SUMS).

Features

SFTP, SCP and FTP

SSH, plain FTP and FTPS (explicit or implicit TLS), passive or active.

SSH keys

Log in with a key file (OpenSSH or PuTTY .ppk) or your SSH agent, as well as passwords.

Two panes

This computer on the left, the server on the right; drag and drop between them.

Several connections

Each in its own tab and colour, with its own transfer lists.

Safe transfers

Asks before replacing files; interrupted transfers continue where they stopped.

Passwords kept safe

Saved in GNOME Keyring or KWallet on Linux, the Keychain on macOS and the Credential Manager on Windows, never in a plain file.

Signed updates

Updates are only offered when signed with the ShuttleSCP release key.

Build from source

You need Rust 1.88 or newer and GTK 4: on Linux its development files (libgtk-4-dev on Debian and Ubuntu, gtk4-devel on Fedora), on macOS from Homebrew (packaging/macos/install-build-deps.sh installs it):

git clone https://github.com/dsalvado/shuttlescp.git
cd shuttlescp
cargo run --release

On a Mac, packaging/macos/run-dev.sh runs it as an app, with its own icon in the Dock. On Windows, GTK comes from MSYS2 and Rust builds with its GNU toolchain; see BUILDING.md.
